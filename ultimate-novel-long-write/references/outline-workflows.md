# 长篇开书、大纲与细纲工作流

## 目录

- 开新书
- 章纲
- 重大走向推演
- 细纲共创扩写

## 开新书

### 锁定方向

选题未定时加载 `ultimate-novel-long-scan`；方向已经明确时不强迫重做扫榜。最终方向说清一句话题材、目标读者体验、核心卖点与差异、主角可见目标、最早阻力和长期可持续引擎。选题与核心卖点由作者确认后再写入正式设定。

### 确认创作核心

把以下内容作为一次整体决策，不拆成连续小问题：

- 主角欲望、底线、长期目标、稳定底色和主要变化轴；
- 主角不能变成什么样；
- 核心能力的用途、限制和代价；
- 主要对手如何主动制造压力；
- 情绪底色及核心爽点、虐点、悬念或关系期待；
- 前几章向读者交付什么承诺；
- 长篇持续连载不能丢掉的东西。

需要方案时给出真正有区别的候选和推荐理由，不以更道德、更稳妥或更方便流程化为推荐依据。

### 组装故事

围绕“人物欲望—当前阻力—人物行动—真实代价—能力或关系变化—阶段兑现”建立可持续因果。关键配角有自己的利益和决定，不只承担夸奖、送信息和递剧情。设计主角、主要配角和主要对手时，按 [项目状态结构](../../ultimate-novel/references/project-state-schema.md) 的人物卡写出说话习惯，起名按长篇写作主文件“写正文”里的起名规则。

### 总纲、卷纲与滚动细纲

总纲稳定开篇承诺、长期目标、核心冲突、升级路线、主要人物变化轴、大阶段结算和结局方向。卷纲负责阶段目标、新阻力、得失、关系变化、伏笔与卷末兑现。

细纲滚动规划，通常只做当前能够可靠判断的连续章节，不一次写完整本书的逐章细纲。作者已有明确数量时服从作者，不用固定章数覆盖项目需要。

### 黄金三章

黄金三章作为一个整体设计：第一章建立具体处境、异常或冲突；第二章让卖点通过人物行动真正运转；第三章完成第一次明确回报并打开长期目标。三章不能只是同一种刺激重复。

黄金三章整体方向由作者确认后再进入后续正式写作，不要求作者逐章进行形式化审批。

## 章纲

正式章纲使用最小充分字段，不为填表写空项：

```markdown
# 第XXX章（工作标题可选）

- 本章目标与结束时的真实变化：
- 时间、开场状态及与上章承接：
- 核心冲突与读者等待：
- 主角及其他关键人物的选择：
- 新信息、知情与证据变化：
- 角色、能力、关系和伏笔变化：
- 必须正面呈现的场景：
- 章末兑现、余味或下一步：
- 作者原句与硬禁区：
```

只有关键选择命中 `character-causality.md` 的书面行动账条件时，附相应记录。没有倒计时不创建倒计时字段；不把每个日常动作精确到分钟。

章纲必须回答“本章结束后什么真正变了”。变化可以落在事实、选择、关系、理解、生活状态、读者期待或情绪上；闲谈、低压生活和氛围段有真实读感作用时不因此压缩。

## 重大走向推演

开新卷、核心反转、阵营变化、长期关系决裂、主要角色生死或故事线替换时：

1. 把真正不同的方向放入候选区；
2. 比较读者期待、人物动机、节奏、伏笔、代价、风险及长期意图；
3. 清楚标注候选，不进入正史；
4. 等作者选定；
5. 只将已选方案增量同步到正式大纲和追踪文件。

长篇换卷或核心转折时，按 [世界运转与暗线推演](../../ultimate-novel/references/world-offscreen-progress.md) 推进一次暗线、重选当前卷层，把各方已推进到的位置作为比较候选方向的依据之一。暗线推演只进暗线表，不替作者选方向。

## 细纲共创扩写

只有作者主动提出“先看细纲再补充”“我给细纲，你扩写”等同类意图时使用，不设为所有章节的默认审批。

### 交付可编辑细纲

作者尚未提供细纲时，根据已确认大纲、章节事实、当前状态和近期重点先生成细纲，不写正文：

```markdown
# 第XXX章细纲

## 本章目标与结果
- 本章要完成：
- 结束时发生的变化：

## 事件与选择顺序
1.
2.
3.

## 关键人物
- 当前处境与目的：
- 关键选择及必要依据：
- 情绪如何影响注意、措辞、行动或余波：

## 关键对白
- 必须保留的原句：
- 只需保留的对白意图：

## 章末落点
- 兑现、余味或下一步：

## 禁止改变
- 
```

模板由 AI 先完成，不要求作者填表。作者可直接改几句或用自然语言补充。细纲写清动作、反应、信息、选择与结果，不能只写“发生冲突、感情升温、留下悬念”。

### 等待与合并作者补充

交付细纲后停下，不提前生成正文。作者补充的人物反应、关键对白、事件顺序、最终结果和禁揭内容按以下边界处理：

- 事件结果、顺序和硬禁区属于硬约束；
- 要求原样保留的对白不擅改；只给对白意图时按人物自然表达；
- 人物反应不写成相反态度；
- 与正史冲突时指出具体冲突并让作者裁决；
- 没有冲突时直接进入扩写，不再要求第二次形式确认。

### 扩写正文

补全场景、必要环境、动作因果、非关键对白、人物感知、段落节奏和章末收束。不得改变作者决定的因果、结果、关键选择、必须保留的原句、人物态度和禁揭内容，也不得新增会改变正史的重要身份、能力、关系和支线。

新增内容可以承担人物、关系、情绪、氛围、空间、生活质感、节奏和阅读余味，不要求句句推进；既无读感作用又不改变任何内容的空转才压缩。

作者已提供完整细纲时直接核对事实与硬约束后扩写。作者说“先看细纲”时不把细纲和正文一起交付。正文完成后回到主 Skill 的审查、正史提交和增量同步流程；作者只看草稿时不更新正史。
