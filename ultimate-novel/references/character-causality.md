# 人物因果与故事条件

## 适用范围

在正式大纲、细纲、正文、实质改稿或逻辑审查中，人物的选择会改变主线、关系、身份、资源、安全、权力或长期后果时，使用本规则。普通问答、日常动作、语气、停顿和不影响结果的反应不建账。

人物行动、不行动、撒谎、隐瞒、相信、怀疑、误判、服从、拒绝、默认和态度转变，只在实际影响结果时视为关键选择。群体场景按各人的利益与信息判断，不能只让所有人配合领头者或主角。

## 行动七问

1. **知情**：人物此刻知道什么、不知道什么？信息来自亲见、他人告知、经验、猜测、谎言还是有来源的误判？相信到什么程度？
2. **动机**：想得到什么，最怕失去什么？当下最直接的欲望、利益、压力或恐惧是什么？
3. **人物一致性**：是否符合已建立的性格、关系、底线、身体和情绪状态？反常时是否已有触发？
4. **能力条件**：是否具备行动所需的能力、资源、体力、位置和时间？伤势、限制和未知风险是否仍在？
5. **选择逻辑**：这个办法为什么对当前人物有吸引力或可以接受？更安全、更便宜、更文明或可逆的方案存在，不自动证明原选择错误；只有人物当时确实会注意、能够采用，并且没有人物原因放弃时，才构成逻辑缺口。
6. **人物独立性**：去掉“作者需要推进剧情”，人物在当时条件下仍会这样选吗？
7. **后果反馈**：选择造成什么真实结果？其他人物、势力和环境是否按各自利益反应？

人物可以因冲动、面子、偏见、侥幸、欲望、误判和关系压力放弃更优方案。逻辑审查不把人物修成最安全、最文明或最理性的版本。

## 书面行动账

只有以下情况建立书面行动账：

- 改变主线、核心关系、身份、资源、安全或长期目标；
- 高风险、不可逆或会触发多人利益反应；
- 当前确实存在争议，需要跨章保留证据；
- 使用新信息完成关键反转或重要决定。

多个选择的知情、动机、方案与后果相同，可以按一条因果链合并；不同关键选择不能用一行概括整章。

```markdown
| 人物与选择 | 知情与相信程度 | 动机、损失与当前状态 | 能力与替代方案 | 后果与他人反应 | 证据及结论 |
|---|---|---|---|---|---|
|  |  |  |  |  | 通过 / 阻断 |
```

证据必须定位到作者本轮决定、正史、人物卡、角色状态、章节事实、前文或本场景已发生的可见事件。“按常理”“读者知道”“剧情需要”和创作者脑内补充不是证据。

任一关键条件无依据，或选择只能靠“推进剧情”成立时，先补触发、换行动、删情节，或明确写成有来源并承担后果的误判，不得直接提交正史。

## 写后盲审

正式交付前从最终成稿重新反推关键选择，不采信写前行动账和写作者意图。逐项定位人物获得信息的事件、欲望和关系来源、放弃方案的理由及他人的利益反应；正文找不到的依据视为不存在。

盲审与其他检查合并为一次与任务规模相称的复核，不拆成多套重复流程。阻断存在时保持草稿状态，不同步章节事实、角色状态、时间线和伏笔。

## 人物变化与重大刺激

能力、财富、地位和外部待遇变化，不自动等于人物已经成长。人物新状态只有在正文出现足以改变理解或选择的具体事件，并留下可追踪影响时才成立；不得借用未来成熟状态替当前行动兜底。

重大刺激真正触及人物当前欲望、恐惧、关系、利益或处境时，让影响通过心理、注意、理解、措辞、信息控制、动作、行动顺序、选择或延迟余波中最适合此人的方式出现。不强制哭喊、失控、犯错或外显反应；有依据的克制、麻木和迟发同样成立。

## 非公开信息披露

叙述、人物内心和后台设定中的信息，不自动属于对话对象。人物透露会影响安全、权力、交易、信任或后续选择的身份秘密、力量来源、后台机制、控制边界、限制、弱点和计划时，核对听者原知情、说话者收益、披露精度及少说一些能否达到同一目的。

没有利益、压力、关系、信任或有来源的误判支持时，不让人物为方便解释剧情主动泄密。价格、公开常识、必要操作和双方已知事实不因此增加审计。

## 空间、数量与现实尺度

只有人物选择、危险或结果依赖距离、范围、速度、时间、负重、容量、数量、价格或兑换比例时才核算。相关条件必须能同时成立，但正文不展示作者计算过程。

精确数值已由正史锁定时不得冲突；模糊表达不改变事实时可以自然使用。没有给出无关精确数字不属于问题。
