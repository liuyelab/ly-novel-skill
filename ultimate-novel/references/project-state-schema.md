# 小说项目状态结构

本文件只提供机械、稳定、需要单一来源的目录与模板。初始化和导入按实际规模选用，不为目录整齐创建空文件。

## 目录

- 长篇最小结构
- 作者长期意图
- 人物卡
- 近期写作重点
- 卷摘要
- 章节事实
- 写作断点
- 导入断点

## 长篇最小结构

```text
小说项目/
├── 设定/
│   ├── 作者长期意图.md
│   ├── 题材定位.md
│   └── 角色/
├── 大纲/
│   ├── 总纲.md
│   ├── 卷纲/
│   ├── 细纲/
│   └── 候选推演/
│       ├── 已采用方案.md
│       └── 暗线表.md
├── 正文/
└── 追踪/
    ├── 近期写作重点.md
    ├── 项目经验.md
    ├── 角色状态.md
    ├── 时间线.md
    ├── 伏笔.md
    ├── 卷摘要.md
    ├── 写作断点.md
    └── 章节事实/
```

世界观、势力、物品、能力体系和其他设定文件按实际需要创建。`暗线表.md` 只在首次触发暗线推演时创建，格式见 [世界运转与暗线推演](world-offscreen-progress.md)。`卷摘要.md` 在第一卷结束时创建。

只记录作者已经明确表达的内容；资料不足时留空或集中询问，不用一般社会观念补足。

## 人物卡

`设定/角色/` 下每个主要人物一份。主角、主要配角和主要对手写全；其余人物一两行身份与关系即可，不为整齐补全。

```markdown
# 人物名

- 身份与当前处境：
- 想要什么／最怕失去什么：
- 底线与软肋：
- 主要关系：
- 说话习惯：
  - 句子长短与节奏：
  - 常用词或口头禅（没有写"无"，不硬造）：
  - 怎么称呼别人：
  - 不说、绕着说或说一半的话：
  - 情绪上来时说话怎么变：
- 首次出场：
```

说话习惯只记作者确认或正文已经写出的；新人物由写作模块按身份、年龄、出身、关系和处境先拟，作者改过的以作者为准。

## 近期写作重点

```markdown
# 近期写作重点

- 当前主推：
- 暂不推进：
- 必须留下的疑点或期待：
- 下次更新条件：
```

只写未来一至三章最需要推进的内容，每次正式提交后增量更新，不写成长篇总结。

## 章节事实

```markdown
# 第XXX章事实

## 新确认事实

## 伏笔变化
- 新埋：
- 推进：
- 回收：

## 状态变化

## 时间变化
```

只记录已经正式提交的正文事实。人物撒谎、误会或回忆不可靠时记录“某角色声称”；草稿、候选和模型猜测不得进入。

## 卷摘要

```markdown
# 卷摘要

## 第X卷 卷名（第XXX–XXX章）

- 主线：三到五句，本卷发生了什么、结果是什么
- 人物处境变化：人物｜从什么到什么｜第几章
- 关系变化：
- 留下未收的线：内容｜埋于第几章
- 本卷收回的线：内容｜第几章
- 退场或转入休眠的人物：
```

一卷最后一章正式提交后追加本卷一节。只写已提交的正史，不写推测和后续计划；每卷不超过约六百字。没有分卷的书，每三十章左右算一段。写到新卷开头，或老人物、旧地、旧线回归时，先读卷摘要，再按摘要定位到对应章节事实。

## 写作断点

```markdown
# 写作断点

- 当前章节：
- 章纲版本标识：
- 正文版本标识：
- 最后完成步骤：
- 更新时间：
- 作者是否在断点后手改：
```

正文或章纲被作者手改后，旧审查和旧事实提取立即过期。

## 导入断点

```markdown
# 导入断点

- 来源位置：
- 来源版本标识：
- 目标项目：
- 最后完成章节：
- 已完成步骤：
- 更新时间：
```

恢复前核对来源变化。变化章节及其后受影响的提取结果标记过期，从最早受影响位置重新核对；不覆盖作者修改，不重做未受影响且已经确认的内容。
