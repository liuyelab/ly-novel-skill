# LY小说Skill

> A Chinese web-novel writing skill for AI assistants (Claude Code, Codex, etc.). Free for non-commercial use; see the license notes at the end.


整理：刘野老师（抖音号 liuyelab）

## 这是什么

LY小说Skill 是一套装进 AI 里用的中文网文写作 Skill（AI 里的模块编号是 `ultimate-novel`，安装和使用时照写就行）。装好以后，你用大白话跟 AI 说要干什么，它会按这套规矩来干：

- **选题**：看方向、比较几个题材哪个好写好卖；
- **开书**：建好项目文件夹，记下你的设定、人物和禁区；
- **大纲**：总纲、卷纲、章纲，一层一层往下拆；
- **写正文**：长篇、短篇都能写，人物每做一个关键选择都要过"行动七问"；
- **世界运转**：主角不在场时，反派和各方势力也按自己的算盘往前走；
- **说话习惯**：主要人物各有一张人物卡，写清楚他怎么说话，不会一个腔调；
- **起名**：人名要贴合人物的家庭、年代、地域和阶层，同一本书里主要人物的名字不重复、不撞音、不只差一个字；
- **写长了不忘事**：每章记账（人物状态、时间线、伏笔、本章事实），每卷写一份卷摘要，老人物、旧伏笔回来时先翻摘要再找原章；
- **审稿**：查逻辑、查前后矛盾、查人物是不是在给剧情打工；
- **去 AI 味**：让文字更像人写的，而且不会越改越短；
- **书名、简介、封面**：从正文里长出来，不硬套模板；
- **数据复盘**：发布后根据点击、追读、完读数据找问题。

## 需要什么

下面这些任选一个就行：

- **豆包电脑版**（免费）
- **WorkBuddy**
- **Claude Code**
- **Codex**
- 其他能装 Skill 的 AI 助手，一般也可以。

不同的 AI，写出来的效果会有差别。

## 安装

GitHub 在国内有时打不开，或者很慢。打不开就多试几次，或者换个网络再试。

### 第一种：一句话安装

直接跟你的 AI 助手说：

> 帮我把 github.com/liuyelab/ly-novel-skill 里的 Skill 全部装上

它会自己下载并装好。装完如果它说要重启，就关掉再打开。

这样没装成（比如 AI 打不开 GitHub），就用下面的第二种。

### 第二种：下载 ZIP

1. 点本页右上方绿色的 **Code** 按钮 → **Download ZIP**，然后解压，记住解压出来的文件夹在哪。
2. 把这个文件夹的路径告诉你的 AI 助手（路径就是文件夹上方地址栏里那串字，点一下就能复制），再跟它说：

> 帮我把这个文件夹里的 Skill 全部装上

它会自己装好。装完如果它说要重启，就关掉再打开。

### 手动复制（备用）

上面两种都没装成，就自己复制：

1. 打开解压出来的文件夹。
2. 把里面所有 `ultimate-novel` 开头的文件夹（一共 15 个），整个复制到下面的位置：
   - 用 **Claude Code**：`C:\Users\你的用户名\.claude\skills\`
     苹果电脑是 `~/.claude/skills/`
   - 用 **Codex**：`C:\Users\你的用户名\.codex\skills\`
     苹果电脑是 `~/.codex/skills/`
   - 用豆包、WorkBuddy 等其他助手：放的位置各不相同，直接问它"Skill 文件夹在哪"。
   - `skills` 文件夹不存在的话，自己新建一个。`.claude`、`.codex` 是隐藏文件夹，看不到的话，在资源管理器的"查看"里勾选"隐藏的项目"。
3. 关掉你的 AI 助手，重新打开。

装好以后，复制进去的应该是这个样子：

```text
skills/
├── ultimate-novel/
├── ultimate-novel-long-write/
├── ultimate-novel-review/
└── ……（一共 15 个）
```

## 第一次怎么用

1. **新建一个空文件夹**当你的小说项目，比如 `D:\我的小说\书名`。
2. **让你的 AI 助手打开这个文件夹**：在助手里打开或选中它；不会的话，直接把文件夹的路径告诉助手。
3. **直接说你要干什么**。第一句可以这么说：

> 用 ultimate-novel 帮我开一本新书。题材是______，主角是______，想写给______看。我不想要的是______。

之后常用的说法：

| 你想干什么 | 这样说 |
|---|---|
| 不知道写什么 | 帮我比较这三个题材哪个好写：______ |
| 做大纲 | 帮我出总纲 / 第一卷卷纲 / 第 5 章章纲 |
| 写一章 | 按第 5 章章纲写正文 |
| 接着写 | 继续 |
| 审稿 | 审一下第 5 章 |
| 去 AI 味 | 第 5 章去 AI 味 |
| 已经写了一些 | 把我已经写的前 30 章导入进来，准备续写（先把文件放进项目文件夹） |
| 起书名封面 | 给这本书起书名、写简介 |
| 看数据 | 这是我第 10 章的后台数据，帮我看看问题在哪 |

## 推荐顺序（写长篇）

开书 → 选题 → 设定和人物卡 → 总纲 → 卷纲 → 章纲 → 写正文 → 审稿 → 去 AI 味 → 书名封面 → 发布后看数据

不用每步都走。已经想好写什么，就从设定开始；已经写了一半，就从"导入"开始。

## 几个用好它的习惯

- **动笔前，先让 AI 拆十本同类型的书**。去你要发的小说平台，找同类型排在前面的十本书，让 AI 拆一遍：开头怎么抓人、节奏怎么走、爽点怎么排、文风什么样。拆完再开写。别拿着 Skill 当许愿池，什么都不看就让它写。可以这样说：

  > 用 ultimate-novel-benchmark，帮我拆一下番茄上______题材排前面的十本书。

  如果你的 AI 打不开网站，就自己把那几本的前几章存成文件，放进项目文件夹，让它读。
- **一次写一章**。一口气要十章，质量会往下掉。
- **写完让它审一遍**，有问题当场改。
- **重大决定你来拍板**：谁死谁活、站哪个阵营、什么时候揭秘，它会先问你，不会自己定。
- **你自己改过的地方告诉它一声**，它会以你改的为准，不会覆盖。
- **说"继续"**，它会接着写当前这一章或这一场，不会自己往后跑好几章。
